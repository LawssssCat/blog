## 银行卡

基础概念

+ 存折 —— 只能线下柜台存取钱的纸质小本子，特点支持定期存款（在与银行约定的时间后才取出存款的话，有更高的定期利息）
+ 储蓄卡 —— 只能线下用，不支持网购的借记卡
+ 借记卡（Debit Card） —— 先存后消费
+ 信用卡（Credit Card） —— 先消费后还款
+ 有效期 —— 信用卡有效期一般在5~8年
+ 账单日 —— 消费的还款区间
+ 还款日 —— 需要在最后还款日前，完成对两个账单日间的消费进行全额还款/最小额度还款。最后还款日一般是账单日的后第18天
+ 年费 —— 除了高端信用卡每年要几百几千美金外，其它卡一般都免年费/有条件免年费了
+ 手续费 —— 资金在不同体系间转换的人为损耗
+ 权益
  + 固定额度⭐
  + 临时额度
  + 取现额度
  + 超额额度
  + 共享额度

### 借记卡/储蓄卡

规定

+ 一类卡、二类卡 —— 国内xxxx年规定的借记卡分类，规定个人在商业银行的第二张卡只能是二类卡，目的是规范账目。
  + 一类卡：全功能账户
    + 可以大额转账，收款、消费没有限制
    + 可以跨境汇款（但有限额）
    + 可以购买理财产品等金融产品
  + 二类卡：功能有限
    + 不能大额转账，收款、消费都有限制
    + 不能跨境汇款
    + 可以购买理财产品等金融产品

种类

+ 内地 —— 有外汇额度，每月1w~5w左右，每年10w~20w左右
+ 香港
  + 区别
    + 办卡比国外方便，不像如美国、新加坡办卡需要签证、居住证明、税务材料等
      + 资料
        + 身份证、港澳通行证：有效期大于6个月
        + 手机号
        + 地址证明：信用卡邮寄账单
        + 社保证明、工资流水、投资证明
    + 可参与港美股、全球债券 —— 对办卡地有限制
    + 利率不同 —— 定价人不同
    + 转外汇 —— 看有没有开账号

### 日本

参考：

+ 冷水TV|日本财团介绍 - <https://www.youtube.com/watch?v=lth_yyRNpPM>

财团御三家：以家族经营方式在各个领域控股的大型垄断集团。通过资本力量影响国家经济政策和社会结构。

::: tip
财团 —— 原“财阀”，二战战败后资产被冻结，子公司被拆分有各自自主权，但为了经济复苏抱团取暖，形成如今“财团”。
:::

+ 三菱（MITSUBISHI） —— | 路径： 公务员（信息） => 倒爷（资金、人脉） => 海运（技术） => 矿业（海运能源）、保险（海运风险）、仓库（海运物流） => n | 产品： 三菱商事、三菱重工、三菱UFJ银行、三菱汽车、三菱电器、麒麟啤酒、罗森、...
+ 三井（MITSUI） —— | 路径： 和服（资金） => 金融（政商） => 风投（扎根各行各业） => n | 产品： 三井物产（基建）、三井不动产（基建）、三井住友金融集团、工业、矿业、丰田（TOYOTA）、东芝（TOSHIBA）、三越百货（MITSUKOSHI）、富士胶卷、札幌啤酒、东京巨蛋、...
+ 住友（SUMITOMO） —— | 路径： 天皇曾孙（信息、人脉） => 炼铜（资金、技术） => 矿业、金融业（政商） => n | 产品： 住友商事、住友电工、日本电器（NEC）、川崎重工、大阪商船、雅马哈发动机
+ 富士（FUJI） —— 产品： 日产（NISSAN）、日立（HITACHI）

> 众所周知，御三家有四个。
